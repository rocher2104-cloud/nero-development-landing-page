Security & Governance

Real-world capture demands real controls.

Nero collects data inside working businesses, from real people. Consent, privacy and data-handling controls are built into the collection pipeline, not layered on afterward.

Security pillars

01

Consent

Workers appearing in captured footage are informed as part of the site deployment agreement.

02

Redaction

Faces, identifying marks or other sensitive elements can be redacted per program specification.

03

Access control

Raw and processed data access is restricted to the systems and personnel a program requires.

04

Encryption

Data is encrypted in transit from capture hardware and at rest in Nero's pipeline.

05

Retention

Retention periods for raw capture and processed datasets are set per program agreement.

06

Client data isolation

Exclusive and continuous programs are isolated from data delivered under non-exclusive licenses.

Data Lifecycle Controls

Controls apply at every stage, not just at delivery.

  1. CAPTURE

    Consent and site agreement in place prior to any recording.

  2. INGEST

    Encrypted transfer, integrity verification, access-limited storage.

  3. PROCESS

    Redaction applied where the program specification requires it.

  4. ENRICH / VALIDATE

    Annotation and QA access limited to authorized personnel and systems.

  5. DELIVER / RETAIN

    Delivery under agreed license terms; retention and deletion per contract.

This page describes Nero's approach to data governance at a program level. Specific certifications, compliance frameworks and audit documentation are provided under NDA as part of a customer or site-host agreement.
